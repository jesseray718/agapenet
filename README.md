# agapenet

**Agape-oriented networking and cooperation fabric within the OpenRoot lattice.**

## What this is
Networking and mesh-oriented patterns intended to support cooperative, offline-capable systems.

## Role in the Lattice
Provides networking-oriented pieces that align with the Agape cooperation layer and the wider mesh tools (Reticulum, LXMF, etc.).

## Bigger Picture
Communication that still functions when infrastructure is intermittent is required for any real offline-first lattice. This repository contributes to that capability under a cooperation-first design.

## Current Status
Supporting spoke.
